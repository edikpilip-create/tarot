# Button Registry

This document tracks the stable button and navigation identifiers used by the localized landing page and Telegram source payloads.

| ID | UI label source | Target / role |
| --- | --- | --- |
| `brand-home` | `buttons.brand` | Scroll to `#top` |
| `nav-wisdom` | `buttons.navWisdom` | Scroll to `#wisdom` |
| `nav-structure` | `buttons.navStructure` | Scroll to `#structure` |
| `nav-spread` | `buttons.navSpread` | Scroll to `#spread` |
| `nav-contact` | `buttons.navContact` | Scroll to `#contact` |
| `hero-draw-spread` | `buttons.heroCta` | Jump from hero to `#spread` |
| `spread-draw` | `buttons.spreadDraw` | Trigger the 3-card draw interaction |
| `submit-lead-form` | `buttons.submitIdle` / `buttons.submitSending` | Submit the lead form |

Form identifier:

| ID | Role |
| --- | --- |
| `lead-form` | Contact / Telegram submission form |
